OpenExile3 is an independent compatibility/reimplementation research project.

Some renderer behavior, data-structure comparisons, classic monster-picture mappings, trim logic, road-frill logic, and related implementation references were derived from the GPLv2 release of **Blades of Exile** source code. The prototype is therefore distributed under GPLv2; see `LICENSE.txt`.

The original Exile III game data, executable, graphics, sounds, and save games remain Spiderweb Software material and are **not included** in this package. Users must point OpenExile3 at their own existing Exile III installation.
